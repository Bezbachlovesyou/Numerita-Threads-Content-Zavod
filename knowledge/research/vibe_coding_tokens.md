# Осознанный вайб-кодинг: токены, лимиты Claude Code, темп без выгорания (30.10.2026)

Конспект для владельца и для Нумериты-продюсера. Написан по устройству Claude Code и практике этого проекта.
Большое веб-исследование не проводили: оно само съело бы лимиты, которые мы бережём. Тарифы и лимиты Anthropic
меняются, поэтому точных чисел здесь нет — смотреть /usage (или /status) в самом Claude Code.

## Как тратятся лимиты
- Каждое сообщение отправляет модели весь контекст сессии: инструкции (CLAUDE.md), историю, прочитанные файлы,
  вывод команд, скриншоты. Кэш удешевляет повторное чтение, но не обнуляет его.
- Поэтому чем длиннее сессия, тем дороже каждая следующая реплика, даже короткая «да».
- Главный расход этого проекта: CLAUDE.md завода (~97 КБ) и основного бота (~265 КБ) загружаются в каждую
  сессию, где подключены оба репозитория. Это больше 100 тысяч токенов ещё до первого вопроса.
- Дорогие действия: субагенты и «исследуй всё» (каждый агент — отдельный большой контекст), чтение больших
  файлов целиком, длинные логи, много скриншотов, рендер и просмотр кадров видео, Opus вместо Sonnet на простом.

## Правила экономии (по убыванию эффекта)
1. Одна задача — одна сессия. Закончили тему — /clear или новая сессия. Не держать сутки один чат.
2. Подключать к сессии только нужный репозиторий: работа над заводом — без основного бота, и наоборот.
3. CLAUDE.md — короткий указатель (до ~200 строк): принципы и где что лежит. Подробные истории решений —
   в docs/, модель читает их только по ссылке, когда нужно.
4. Модель по задаче: простые правки, тексты, вопросы — Sonnet (/model); Opus — архитектура и сложные баги.
   Режим «быстро» (fast) и максимальное усилие — только когда реально нужно.
5. Пачка вместо капельницы: одно сообщение с тремя поручениями дешевле трёх сообщений.
6. Скриншот — обрезанный до нужного места; голос — коротко, по сути.
7. Не просить «изучи весь рынок / весь интернет» без нужды — это самые дорогие запросы.

## Что выносить из Claude Code
- DeepSeek, ChatGPT, бесплатный Claude.ai в браузере: мозговой штурм, тексты постов, идеи рубрик, перевод,
  вопросы «как устроено X», разбор референсов. Готовое — одной строкой сюда или прямо в пульт.
- Пульт завода (ops/commands.json) и команды бота: повторяемые действия без долгих разговоров.
- Сам завод: обходы, отчёты, переписка постов делают дешёвые модели внутри бота (OpenRouter), а не Claude Code.
- Claude Code оставлять для кода, выкладки, отладки и решений, где нужен доступ к репозиторию.

## Осознанный вайб-кодинг (практика)
- Зачем → что → как: перед задачей одна строка «зачем и как поймём, что сработало».
- Маленькие проверяемые шаги: одна функция — тест на фейках — выкладка — квитанция. Не десять идей за вечер.
- Фокус на узком звене (Голдратт): сейчас это переход «пришли в бота → оплата», а не новые форматы постов.
  Новые рубрики без замеров — расход токенов и внимания без выручки.
- Каждую неделю: что дало деньги или людей (цифры /performance и воронки), что убрать (алгоритм Маска:
  усомнись → удали → упрости → ускорь → автоматизируй).

## Темп без выгорания
- Сон и режим — основа (режим владельца: к 21:00 сворачиваемся). Ночные сессии самые дорогие и по токенам,
  и по качеству решений.
- Окно работы: 1–2 фокусных блока в день с ясной целью, а не непрерывный поток мелких поручений.
- Лимит закончился — это пауза, а не катастрофа: завод работает сам, без Claude Code.

## Путь к первой выручке
- Одна гипотеза в неделю про оплату (оффер, цена, пробный период, путь из Threads в бота), одна цифра успеха.
- Ценность — в обмен на деньги: польза бесплатно, глубина (полный разбор, совместимость) — платно.
- Больше людей — через то, что уже работает лучше всего (по замерам), а не через новые площадки сразу.
