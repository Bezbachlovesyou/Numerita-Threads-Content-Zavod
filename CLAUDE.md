# Numerita Threads Content Zavod — краткие правила

Telegram-бот, который сам ведёт Threads Нумериты (RU @numerita.ai, EN @numerita.love), канал @Numeritalovesyou
и Instagram: пишет посты по базе знаний, публикует через Zernio, отвечает на комментарии, ведёт людей в @Numeritabot.
Полная история решений владельца с датами и деталями — docs/decisions-log.md (читать нужный раздел через grep,
а не целиком). Новое решение владельца: одна строка сюда, если это общее правило; подробности — в decisions-log.md.

## Основа и кредо
- Саттвическое даяние (Гита 17.20): дар без ожидания ответа, вовремя и тому, кому нужно. Каждый пост, ответ, ссылку
  проверяем: это дар человеку или расчёт на выгоду.
- Кредо: сияние и звёзды, любовь и радость, поддержка и опора, вдохновение и мотивация. Любовь — сквозная тема
  (через поступки, без обещаний любви по числам). «Из каждой оказии — виктория»: из каждого сбоя — победа.
- Нумерита — ангел-хранитель человека, который опирается на числа, звёзды и науку. Образ неизменен
  (assets/numerita_angel.jpg); канон видео — docs/numerita-visual-canon.md.

## Принципы работы с владельцем
- Всё автоматизирует ИИ, без одобрений; владельцу — только проблемы и короткие отчёты (1–3 строки, решение одной
  строкой с вариантами). Простыни не слать. Отвечать по-русски, коротко, без жаргона.
- Ближе к 21:00 МСК мягко отправлять владельца спать.
- Владельцу остаётся только то, что нельзя из кода (ключи Railway, шапка профиля, права) — объяснять по шагам.
- Платные генерации — только после сметы одной строкой и «да» владельца на сумму; в коде жёсткий потолок.
- «Вышло/готово» — только по квитанции площадки, не по факту «сервис принял».
- Абсолютная честность (knowledge/honesty_policy.json): факт, традиция, символ и гипотеза различаются; без обещаний
  дохода, любви, будущего; не выдумывать цитаты.
- Приватность владельца: не упоминать, откуда он, где живёт и какими инструментами сделана Нумерита.

## Устройство
- `zavod/` — Python, aiogram 3, `python -m zavod`; Railway (NumeritaCZThreadsbot), деплой из `main`; Postgres.
- Посты — OpenRouter по базе https://numerita.up.railway.app/kb.json; ответы — Haiku 5.5 в дневном бюджете
  REPLY_BUDGET_USD; ответы кодом выключены (CODE_SHARE = 0).
- Ритм: autopost.py сам выбирает время (днём 200–260 мин, вечером 18–23 МСК 45–60 мин, ночью реже), не больше
  20 постов в сутки; рубрики по весам; optimizer.py раз в сутки правит веса. Фиксированного расписания нет.
- Промпты: brand_voice.md, reply_voice.md, playbook.md (хуки, цельность, юмор), threads_rules.md, content_plan.md
  (все рубрики), abundance.md, threads_script.md.
- Пульт: ops/commands.json в main (репозиторий публичный — ни ключей, ни личных данных); бот читает раз в 5 мин,
  действия post / thread / grid / unpublish / ig / reels_on / reels_off / raw_clips.
- Английский экземпляр — тот же сервис, FACTORY_LANG=en, схема «en», свои лимиты прогрева.
- Обходы constraint.py в 11/15/19 (Голдратт и теории роста): обратимые меры на 12 ч, необратимое — вопрос с ‼️.
- Телеграм-канал: переносы из Threads на паузе (REPOSTS_PAUSED); суд/протоколы в канал не идут.

## Публичный контент
- Фокус — нумерология: в каждом посте числа/дни рождения, узнавание, хук в первой строке, повод ответить.
  Цельность: одна мысль и один образ (coherence_gate), антидубль (textguard), фильтр рисков (safe_gate).
- Текстовый режим (THREADS_TEXT_ONLY=1, CARDS/VIDEO off); исключения: живые матрицы «Угадай число» — только видео,
  записки от числа, отдельные разрешённые ролики (media_kind).
- Табу: политика, война, силовики, суды, трагедии, криминал, болезни, насмешки над людьми и народами.
  Юмор — над ситуацией (Жванецкий/Задорнов по приёмам, без их тем).
- Без призывов «отметь/перешли/сохрани/пиши в лс», без конкурсов и розыгрышей (engagement bait понижается).
- Имена: не рекламировать авторов референсов и конкурентов (в т. ч. Капустина, Торсунова, Хакимова); упоминать
  мыслителей и учёных в обсуждениях можно; знаменитостей — только в рубриках text_hype/text_celeb по их правилам.
- Языки не мешаем никогда: RU без английских вставок, EN без единой кириллической буквы (lang.has_cyrillic).
- Ссылки на бота всегда с меткой `t.me/Numeritabot?start=ad_th_<метка>` (EN — ad_en_th_).

## Ответы на комментарии
- Голос и паспорт персоны — prompts/reply_voice.md. Польза прежде приглашения; ссылка — по просьбе или в режиме
  offer (дата/число, одному человеку раз в 30 дней, в общих лимитах ссылок).
- 5 бесплатных ответов человеку в сутки (3 при 70% бюджета), последний — с приглашением в бота.
- Безопасность Threads: не больше 25 ответов в час и 250 в сутки, паузы 45–100 с, при 429/403-80016 — долговечная
  пауза. Не приближаться к блокировке; лимиты не повышать без слова владельца.
- Кризисные слова — CRISIS_REPLY с линией помощи, без нейросети.
- Удаление: посты с подтверждёнными 0 лайков и 0 комментариев (zero_cleanup, по правилам из decisions-log.md);
  1–3 лайка без комментариев — перерабатывать, не удалять.

## Перед пушем
`python -m py_compile zavod/*.py` и проверка изменённой логики на тестовой базе (SQLite и Postgres) с подставными
Zernio, Telegram и нейросетью. Реальные посты и ответы из песочницы не отправлять. Тесты — проверять вывод «OK».
