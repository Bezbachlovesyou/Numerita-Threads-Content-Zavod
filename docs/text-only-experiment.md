# Текстовый поток Threads — 27.10.2026

Поручение владельца: попробовать полностью текстовый поток, больше юмора, короче,
меньше назидательного тона. Это эксперимент, не доказанный закон эффективности.

## Режим

THREADS_TEXT_ONLY=1, CARDS=off, VIDEO=off в целевом NumeritaCZThreadsbot.
Код также включает этот эксперимент по умолчанию. Для явной отмены установить
THREADS_TEXT_ONLY=0 и отдельно выбрать CARDS/VIDEO. Период не завершается самовольно.

Генерация видео остановлена; не загружаются карточки, карусели и старые видео из
локальных черновиков. На последней границе POST /posts удаляется mediaItems даже
при переданных старых image_urls/video_url. Подпись «найди на картинке» без картинки
не выпускается. Само включение текстового режима не удаляет опубликованные посты. Отдельное правило владельца
от 28.10.2026 разрешает удаление постов с перепроверенными 0 лайков и 0 комментариев.

Старая общая очередь queued сохранена и приостановлена для автопотока. Импортирована
отдельная очередь из шести новых коротких текстов без медиа; записи идемпотентны.
Они чередуются с новой генерацией, затем поток продолжают текстовые рубрики.
Уже назначенные локальные scheduled проходят текстовую редактуру перед публикацией.
Неподходящий текст при сбое редактуры не прикрывается отсутствующим изображением.
Отдельно проверяется очередь scheduled в Zernio, а не только локальная БД.

## Форматы

1. Нумерологический чат — 2–4 реплики разных чисел.
2. Служба поддержки Венеры — любовь, красота и смешные бытовые желания.
3. Шуточный суд — привычка числа и её оправдание.
4. Офис чисел — созвон, дедлайн, отпуск.
5. Две реплики на выбор — желания и действия, без настоящих кнопок.
6. Воображаемый отзыв о нумерологическом образе — не отзыв клиента.

Цель 120–280 знаков, максимум 450. Не каждый пост заканчивается вопросом или советом.
Сценка явно вымышленная; не выводить реальный характер/будущее из дня рождения.
Юмор направлен на ситуацию. Нет унижения возраста/пола, ложных отзывов и обещаний денег.
Примеры находятся в zavod/text_mode.py; число 6 и дни 6/15/24 сохраняют любовь,
тепло и творчество как нумерологический образ. Остальные числа — по существующей базе.

## Проверка результата

В БД фиксируется experiment:text-only:started_at. Использовать /performance и зрелые
24-часовые наблюдения: просмотры, лайки, комментарии, доли реакций при наличии views,
переходы и подтверждённые оплаты. Сравнение до/после не равно случайному A/B-тесту:
темы, время и аудитория тоже могут меняться. Не увеличивать частоту ради эксперимента.

81 тест прошёл на изолированной PostgreSQL; SQLite — 60 выполнены, 21 пропущен.
Проверены отказ от изображения/видео на финальной границе, самостоятельность текста,
обратимость режима, выбор текстовых рубрик и сохранность прежней очереди.
Компиляция прошла. Выпуск подтверждается отдельно по SUCCESS, публикация — по URL.
