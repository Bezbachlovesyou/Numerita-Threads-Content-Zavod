# Карусели «Сила без самопотери» — 26.10.2026

## Что внедрено
Рубрика eight_growth: шесть связанных карточек для 8, 17, 26, единая палитра, номера слайдов, подпись и вопрос согласованы с содержанием. Подключена к штатной публикации альбомов. Работает при включённых карточках; без них выходит подпись. Частота и лимиты не увеличены. Добавление в план не доказывает фактическую публикацию.

## Истина
Складывание цифр дня — проверяемый расчёт. Значения чисел — символическая традиция, не установленный факт о человеке. Трудности с оплатой и границами возможны при любой дате. Не утверждаем, что восьмёрки рождены для власти, мораль мешает богатству или у даты есть механизм привлечения денег. Не выдумываем результаты клиентов и не обещаем рост дохода.

## Механика
Обложка с противоречием → рамка достоверности → узнаваемая ситуация → новая опора → упражнение → содержательный вопрос.
Одна мысль на слайд; крупный текст, достаточно воздуха. Не переносить длинные абзацы референса.
Следующее развитие визуала: символ 8 из двух связанных орбит, тепло и свет как образ связи амбиций с заботой. Пока используется штатный звёздный рендерер: отдельный рисунок орбит не реализован.

## Разнообразие
Варианты для следующих экспериментов: сила и отдых; забота и границы; независимость и близость; знания и действие; творчество и завершение. Сначала сверять трактовку числа с KB. Менять ситуацию и упражнение, а не только цифру.
Не добавлять сразу множество рубрик: сначала оценить эту карусель.

## Комментарии и путь к подписке
Ответ опирается на ситуацию, не на предполагаемый характер по дате. Пример: «Назвать цену бывает трудно, когда она ощущается оценкой тебя целиком. Можно начать с состава работы: что входит, какой результат и срок. Ты сейчас называешь цену за час или за готовую задачу?»
Не давать без контекста финансовые предписания. Несогласие с описанием допустимо.
Пользу выдавать в комментариях. Уместный повод подписаться — следующие самостоятельные разборы ситуаций; не требовать подписки за обещанный ответ.
По явному запросу сервиса объяснить, что именно доступно в Нумерите, не выдумывая платные функции; ссылка с меткой и действующими ограничениями. Не обещать, что покупка увеличит доход.

## Проверка эффекта
Сравнить несколько публикаций с сопоставимыми охватами: содержательные комментарии на 1000 просмотров, продолжение диалогов, новые подписки (если доступны данные), переходы с меткой, запуск и повторное использование бота, оплаты. Не приписывать все подписки одному посту без атрибуции. Нет ключа данных — оплаты неизвестны, не нулевые. Просмотры отдельных слайдов API может не отдавать: не выдумывать досматриваемость.
