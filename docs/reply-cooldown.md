# Подтверждённые ограничения автоответов

27.10.2026: исправляется сообщение из скриншота владельца. Слово `rate` в произвольной
ошибке не доказывает, что Threads требует отвечать реже. API-запросы идут через Zernio.

Сохраняются HTTP-статус и Retry-After. При подтверждённом HTTP 429 действует сохранённая
пауза всех запросов автоответов: от 5 минут с экспоненциальным ростом до часа, либо
дольше по Retry-After (не более суток). Новые проходы и перезапуски читают эту паузу.
Текущий проход останавливается, оставшиеся комментарии не отправляются подряд.
Лимиты частоты, бюджет и платные тарифы не повышаются.

Уведомление говорит об HTTP 429 Zernio, источник внутри цепочки Zernio/Threads не
объявляется установленным. Повторные одинаковые ограничения не создают одинаковых
тревог. Восстановление сообщается только после новой подтверждённой отправки ответа,
а не просто после очистки ошибки. Статус публикаций проверяется отдельно.

Старые строковые ошибки без HTTP-статуса не превращаются догадкой в 429. Другие коды
ошибок Meta, переданные внутри HTTP 400, здесь не классифицируются без проверенной
семантики. Тесты используют фейковый API; реальный лимит намеренно не вызывается.


## 28 октября: HTTP 403 / 80016
Скриншот владельца фиксирует отказ получения комментариев с кодом 80016. Причина
платформенного кода по доступной документации не подтверждена: это не следует называть
доказанным баном или обычным исчерпанием квоты. Проверка health 28.10 15:21 UTC:
healthy, canPost=true, права чтения/ответов предоставлены, токен valid. Это не проверка
статуса рекомендаций или гарантии будущей доступности.

Автоответы при сочетании HTTP 403 и отдельного кода 80016 останавливают весь проход.
Пауза сохраняется в БД: 30, 60, 120, 240, 360 минут; Retry-After увеличивает её
при необходимости. История повторов хранится шесть часов от последнего отказа и
не сбрасывается одним удачным ответом. Обычные 403 не объявляются ограничением частоты.
Существующий 429 сохраняет собственную историю и экспоненциальную паузу.
/safety показывает отдельный счётчик и последний 403 без выдуманного процента бана.
Постинг не выключается автоматически по отказу чтения комментариев. Другие аккаунты
не используются для обхода ограничений. Нулевую частоту ошибок не обещаем.
