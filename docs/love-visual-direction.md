# Любовь: визуальное направление Нумериты

Референс владельца: светящийся символический человек держит сердце, тёплая золотая
подсветка контура, мягкие частицы и движение фона. Из неподвижного скриншота можно
считать стиль; движение описано владельцем, исходное видео не предоставлено.
Создаём собственные композиции, не копируем чужой ролик.

## Главный принцип
Хук → человеческий смысл → символ → композиция → движение.
Любовь — постоянный мотив: люди, семья, друзья, любимое дело, природа, планета.
Сердца — часто и регулярно; избегать одинаковой композиции в каждой публикации.

## Первая сцена для отношений
- 8 секунд, вертикальный формат; читается и без звука.
- В начале два светящихся числа на отдельных мягких орбитах.
- Контуры чисел плавно переходят в два абстрактных человеческих силуэта.
- Силуэты сближаются; между ними возникает небольшое тёплое сердце.
- Свет от сердца объединяет пространство, мягкие частицы движутся на фоне.
- Закрыть петлю плавным переходом к исходным числам, без резких вспышек.
- Золото, глубокий синий/фиолетовый и небольшой тёплый красный акцент сердца.
- Хук и призыв читаемы; не двигать длинный текст вместе с фоном.

## Соответствие теме
Для хука «один хочет поговорить, другому нужно побыть одному» сохранить личное пространство:
две отдельные орбиты связаны светом; никто не тянет другого силой, сближение взаимное.
Для «за что полюбили — из-за того спорите» показать одну черту с двух сторон,
затем внимание и понимание, а не объявлять любую пару совместимой.
Для любви к делу — сердце рядом с процессом создания; к природе — забота о живом;
к планете — светящийся земной шар с сердцем. Не подменять смысл одинаковыми украшениями.

## Музыка
Атмосферное мелодичное электронное звучание, ориентир Eli & Fur — You're so High.
Встраивать только музыку с подходящими правами. Не обещать доступ к библиотеке Threads
через API. Без громких ударов и мигающих эффектов; видео сохраняет смысл без аудио.

## Статус
Это спецификация следующей анимации. Текущий прототип two-numbers — два числа и свечение,
ещё без превращения в людей и сердца. Эта запись не меняет рендерер cards.py/video.py.
