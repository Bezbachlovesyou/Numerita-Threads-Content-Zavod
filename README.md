# Numerita Threads Content Zavod

Контент-завод для Threads, которым управляют через Telegram-бота.

## Как это работает

1. Вы пишете боту тему поста (или `/new <тема>`).
2. Claude (через OpenRouter) пишет пост по базе знаний Numerita (`KB_URL`, по умолчанию https://numerita.up.railway.app/kb.json) и правилам из `prompts/brand_voice.md`.
3. Бот присылает черновик с кнопками и голосовое сообщение, где пост зачитывает женский голос в 2 раза быстрее обычного.
4. Кнопки под черновиком:
   - ✅ Опубликовать — сразу в Threads и в Telegram-канал (`TELEGRAM_CHANNEL`, бот должен быть админом канала);
   - 🕒 Через час / Завтра 10:00 — в расписание;
   - 🔄 Переписать — новый вариант на ту же тему;
   - 🔊 Озвучить — прислать голосовое ещё раз;
   - 🗑 Удалить.
5. `/queue` показывает черновики, запланированные посты и посты с ошибками.
6. `/stats` показывает статистику аккаунта в Threads (показы, лайки, ответы, репосты) по последним постам. Под опубликованным постом есть кнопка «📊 Статистика» для одного поста. Данные берутся из Zernio.

7. `/status` показывает, какая модель пишет посты, загружена ли база знаний и что подключено.

8. **Автопостинг без расписания.** Бот сам решает, когда выпустить следующий пост (днём примерно через 70–100 минут, ночью через 110–160, никогда не чаще раза в час) и какую рубрику из `prompts/content_plan.md` взять: сильные чаще, слабые реже, ссылка — не в двух постах подряд. После перезапуска или долгой паузы первый пост выходит сразу. Готовые тексты из `prompts/threads_script.md` выходят первыми, через пост. Каждому посту ставится тема Threads (`Нумерология`, `Отношения`, `Саморазвитие`); в постах со ссылкой ссылка уходит первым комментарием с меткой `t.me/Numeritabot?start=ad_th_<рубрика><число>_<ДДММ>`. `AUTOPOST=off` — выключить. `/plan` — когда следующий пост и веса рубрик.

9. **Автоответы.** Раз в 5 минут бот смотрит комментарии под своими постами за последние 3 дня и отвечает каждому лично по базе Нумериты (число дня рождения → число души → планета → сила → шаг), ссылок в ответах нет совсем (Threads считает их спамом): тех, кто написал своё число, бот зовёт за полным разбором «в шапку профиля». Не больше `AUTOREPLY_PER_HOUR` ответов в час (по умолчанию 30), спам и грубость пропускает. `/replies` — последние ответы.

10. **Самоулучшение.** Каждый день в 04:10 бот сам разбирает неделю (очки поста = ответы + 0,2 × лайки + просмотры / 500): сильные рубрики ставит чаще, слабые реже, в часы с лучшей реакцией постит чаще, самую слабую рубрику переписывает нейросетью и через 3 дня откатывает, если стало хуже, а раз в 2 дня придумывает новую рубрику, проверяет её и оставляет только удачную. Владельцу приходит короткий отчёт; одобрять ничего не нужно.

11. **Картинки к постам.** К каждому посту бот сам рисует фирменную карточку Нумериты 1080×1350 (`zavod/cards.py`, Pillow, бесплатно): космический фон, золотое число и орбита, планета, цепляющая фраза (её модель пишет вместе с постом) и кнопка-призыв — «напиши своё число в ответах», «разбор — в первом комментарии» и т. п. Картинка загружается в хранилище Zernio и прикрепляется к посту; если что-то пошло не так, пост выходит без картинки. Шрифты — `assets/fonts` (OFL). `CARDS=off` — без картинок. Самоулучшение пробует разные палитры и два стиля фразы на картинке (интрига или прямой вопрос) и чаще берёт те, что дают больше реакций.

12. **Методичка и новые форматы.** `prompts/playbook.md` — сводка открытых материалов о росте в Threads и сторителлинге (хуки первой строки, схемы историй, что заходит); добавляется к инструкции каждого поста. Рубрики на проверку: история, непопулярное мнение, список «сохрани», юмор, карусель «9 чисел души» (обложка + 9 карточек с датами и качествами из базы). В первый час после поста бот проверяет комментарии раз в 2 минуты.

13. **Головоломка «Какие 3 числа ты видишь первыми?»** (рубрика `grid`). Бот рисует сетку цифр со спрятанными сочетаниями вроде 777, 1212, 333 (`make_grid` / `render_grid` в `zavod/cards.py`). Люди пишут в ответах, что увидели; автоответ знает, какие числа спрятаны, по базе Нумериты игриво объясняет, на чём сейчас фокус человека и какую энергию несут эти числа, и зовёт написать число дня рождения для разбора. Как часто ставить рубрику, решает самоулучшение.

14. **Видео с Нумеритой** (`zavod/video.py`, fal.ai: портрет — Seedream 4.5, видео со звуком и речью — Seedance 2.0). Образ — по картинкам из `assets/numerita` (или по картинке, присланной боту). Сначала три главных ролика в 1080p: два выходят сразу, главный — утром в 9:00, в нём Нумерита говорит «Истина материальной вселенной — в числах». Дальше — по `VIDEO_PER_DAY` новых роликов в сутки (720p, `VIDEO_RESOLUTION`), текст пишет нейросеть. Каждый ролик бот присылает владельцу файлом — для сторис, канала и Инстаграма. Нужна переменная `FAL_KEY`; `VIDEO=off` — выключить.

15. **Форматы для комментариев:** перекличка «Есть тут рождённые 6, 15, 24?» (`callout`), «кто-то из прошлого вернулся — напиши его и свою дату» (`ex`) и «Женщина-восьмёрка — не подарок. Женщина-восьмёрка — джекпот» (`jackpot`: сначала готовые посты из `prompts/jackpot.md`, потом нейросеть в том же стиле).

Ботом могут пользоваться только админы из `ADMIN_IDS`.

## Запуск

Нужен Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните ключи
python -m zavod
```

### Что вписать в `.env`

| Переменная | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | @BotFather → `/newbot` |
| `ADMIN_IDS` | Ваш Telegram ID, например через @userinfobot |
| `OPENROUTER_API_KEY` | https://openrouter.ai/keys → Create Key |
| `OPENROUTER_MODEL` | Необязательно. По умолчанию `anthropic/claude-opus-5.5` |
| `ZERNIO_API_KEY` | https://zernio.com/dashboard/api-keys |
| `ZERNIO_ACCOUNT_ID` | ID аккаунта Threads, подключённого в Zernio. Пока пусто, посты только сохраняются |
| `TTS_VOICE`, `TTS_RATE`, `TTS_AUTO` | Голос, скорость и автоозвучка. По умолчанию женский голос Светлана, `+100%` (×2), автоозвучка включена |

## Запуск на Railway

1. На https://railway.com нажмите **New Project → Deploy from GitHub repo** и выберите этот репозиторий.
2. В сервисе бота откройте **Variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN`
   - `ADMIN_IDS`
   - `OPENROUTER_API_KEY`
   - `ZERNIO_API_KEY`, `ZERNIO_ACCOUNT_ID`
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` — ссылка на базу Postgres в этом же проекте (если сервис базы называется иначе, замените `Postgres` на его имя).

Бот сам создаст в базе таблицу `posts`. Без `DATABASE_URL` бот хранит данные в файле SQLite (`DB_PATH`), и тогда на Railway нужен Volume, иначе данные пропадут при перезапуске.

Команда запуска (`python -m zavod`) уже прописана в `railway.json`. После каждого пуша в `main` Railway перезапускает бота сам.

## Структура

```
zavod/
  __main__.py     запуск бота и планировщика
  bot.py          команды, кнопки, планировщик публикаций
  generator.py    генерация постов через OpenRouter
  knowledge.py    база знаний Numerita (/kb.json): трактовки чисел и голос бренда
  autopost.py     автопостинг по контент-плану
  autoreply.py    автоответы на комментарии в Threads
  threads_api.py  публикация и статистика Threads через Zernio
  tts.py          озвучка (edge-tts)
  storage.py      SQLite или Postgres: черновики, расписание, статусы
  config.py       настройки из .env
prompts/
  brand_voice.md  голос бренда — отредактируйте под Numerita
  content_plan.md путь клиента и рубрики автопостинга
  reply_voice.md  голос автоответов
  threads_script.md готовые посты с точным временем
```
